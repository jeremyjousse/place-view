# Place view

## iOS display

The iOS app hides the system status bar while a webcam is fullscreen.
Closing the viewer or leaving the place page restores the status bar.
Viewer controls respect the device safe areas.

In the places list, scrolling down hides the bottom navigation.
Scrolling up or returning to the top shows the bottom navigation.
The map and desktop navigation remain unchanged.
